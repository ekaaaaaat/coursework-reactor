# Программный комплекс для моделирования и оптимизации химического реактора окисления бензола C6H6 до малеинового ангидрида C4H2O3

## 1. Общие сведения

### 1.1 Назначение программы

Данный программный комплекс разработан в рамках выполнения курсовой работы и предназначен
для математического моделирования, оптимизации и имитационного исследования химического
реактора с учетом кинетики химических реакций и случайных входных воздействий.

Программа позволяет:
- рассчитывать стационарную математическую модель реактора;
- выполнять оптимизацию параметров объекта проектирования;
- моделировать случайные процессы с заданными статистическими характеристиками;
- исследовать динамику реактора при случайных входных воздействиях.

---

### 1.2 Обозначение и наименование программы

Наименование программы:  
**«Программный комплекс моделирования и оптимизации химического реактора»**

Обозначение программы используется условно и соответствует тематике курсовой работы.

---

### 1.3 Язык программирования и среда разработки

Программа реализована на языке программирования **Python** версии 3.9 и выше.

В процессе разработки использовались следующие библиотеки:
- `numpy` — для численных расчетов и работы с массивами данных;
- `matplotlib` — для визуализации результатов расчетов;
- `tabulate` — для формирования табличного представления результатов.

Разработка и отладка программы выполнялась в интегрированной среде разработки **PyCharm**.

## 2. Функциональное назначение программы

Программный комплекс предназначен для исследования и анализа процессов,
протекающих в химическом реакторе, на основе математического моделирования,
методов оптимизации и имитационного моделирования.

Основными функциональными возможностями программы являются:

- расчет стационарной математической модели химического реактора
  на основе системы дифференциальных уравнений, описывающих кинетику
  химических реакций;

- оптимизация варьируемых параметров объекта проектирования
  с использованием метода золотого сечения;

- генерация случайных процессов с заданными статистическими характеристиками
  (математическое ожидание, дисперсия, корреляционная функция);

- имитационное моделирование входных воздействий на объект управления
  с целью исследования устойчивости и динамики системы;

- расчет динамической модели реактора при случайных входных воздействиях
  и анализ изменения выходных концентраций во времени;

- визуализация результатов расчетов в виде графиков и таблиц,
  обеспечивающих наглядное представление полученных данных.

## 3. Состав и структура программного комплекса

Программный комплекс имеет модульную структуру и состоит из набора
взаимосвязанных файлов, каждый из которых реализует отдельный этап
моделирования, оптимизации или имитационного эксперимента.

### 3.1 Состав программных модулей

В состав программного комплекса входят следующие основные модули:

- **`mat_model.py`** — модуль расчета стационарной математической модели
  химического реактора. Содержит реализацию системы уравнений,
  описывающих кинетику реакций, и функцию для вычисления выходных
  концентраций при заданных параметрах;

- **`golden_ratio.py`** — модуль оптимизации, реализующий метод золотого
  сечения. Используется для поиска оптимального значения варьируемого
  параметра объекта проектирования на основе целевой функции;

- **`simulation_modeling.py`** — модуль имитационного моделирования,
  предназначенный для генерации случайного процесса с заданными
  статистическими характеристиками. Формирует входное воздействие
  для динамической модели;

- **`mat_model_dinam.py`** — модуль динамического моделирования,
  реализующий расчет изменения концентраций компонентов во времени
  при наличии случайного входного воздействия;

- **`README.md`** — файл документации, содержащий описание структуры,
  назначения и порядка использования программного комплекса.

---

### 3.2 Взаимосвязь модулей

Работа программного комплекса организована по этапному принципу.

На первом этапе выполняется расчет стационарной математической модели
реактора с использованием модуля `mat_model.py`.

На втором этапе производится оптимизация параметров объекта
проектирования с применением метода золотого сечения,
реализованного в модуле `golden_ratio.py`.

На третьем этапе формируется случайный процесс с заданными
характеристиками при помощи модуля `simulation_modeling.py`.

На заключительном этапе выполняется расчет динамической модели
реактора с учетом случайного входного воздействия с использованием
модуля `mat_model_dinam.py`.

## 4. Описание логической структуры программы

Программный комплекс имеет последовательную логическую структуру
и реализует полный цикл исследования химического реактора:
от расчета стационарной математической модели до имитационного
моделирования динамики системы при случайных входных воздействиях.

### 4.1 Общий алгоритм работы программы

Работа программы включает следующие основные этапы:

1. Задание исходных физических, кинетических и технологических
   параметров химического реактора.

2. Расчет стационарной математической модели реактора, включающий
   численное интегрирование системы дифференциальных уравнений
   и определение выходных концентраций компонентов.

3. Оптимизация варьируемого параметра объекта проектирования
   с использованием метода золотого сечения.

4. Генерация случайного процесса с заданными статистическими
   характеристиками для моделирования входного воздействия.

5. Расчет динамической модели реактора с учетом случайного
   входного воздействия и анализ изменения выходных параметров
   во времени.

6. Визуализация результатов расчетов в виде графиков и таблиц.

---

### 4.2 Логическая структура и взаимодействие модулей

Логическая структура программы построена по модульному принципу.
Каждый программный модуль реализует отдельную логически завершенную
часть алгоритма.

Модуль `mat_model.py` содержит подпрограммы расчета стационарной
математической модели и используется как на этапе анализа,
так и при оптимизации параметров.

Модуль `golden_ratio.py` реализует итерационный алгоритм оптимизации,
включающий циклы сравнения значений целевой функции и сужение
интервала поиска экстремума.

Модуль `simulation_modeling.py` реализует генерацию случайных чисел,
расчет статистических характеристик, а также циклы формирования
случайного процесса с заданными параметрами.

Модуль `mat_model_dinam.py` использует результаты имитационного
моделирования в качестве входного воздействия и реализует
численное интегрирование динамической модели с использованием
вложенных циклов по временным переменным.

Ветвления в программе используются для:
- выбора типа экстремума при оптимизации;
- проверки допустимых отклонений статистических характеристик;
- перехода к дополнительным расчетам при необходимости уточнения
  параметров модели.

## 5. Описание основных алгоритмов и подпрограмм

В данном разделе приводится описание ключевых модулей программы,
их назначение и логическая структура реализованных алгоритмов.

### 5.1 Модуль `mat_model.py` — математическая модель статики реактора

Модуль `mat_model.py` предназначен для расчета стационарного распределения
концентраций компонентов в реакторе в зависимости от длины реакционной зоны `L`.
Расчет основан на кинетической схеме химических реакций и уравнениях материального баланса.

#### 5.1.1 Исходные параметры и константы

В модуле задаются:
- физические и технологические параметры (температура `T`, диаметр реактора `D`,
  массовые расходы компонентов, плотность среды `ro`);
- параметры кинетики реакций (`A1…A3`, `E1…E3`);
- молярные массы компонентов (`mu_C1`, `mu_C2`);
- варьируемый параметр `L` и шаг интегрирования `d_l`.

Константы скоростей реакций вычисляются по уравнению Аррениуса, что обеспечивает
зависимость кинетики от температуры.


#### 5.1.2 Вспомогательные подпрограммы

В модуле реализованы вспомогательные функции:

- `percent_C(C_m, mu)` — перевод концентрации в массовую долю (в процентах); 
```python
def percent_C(C_m, mu):
    C = (C_m * 100 * mu) / ro
    return C
```
- `f_C1(C1, m)` — правая часть уравнения для изменения концентрации компонента `C1`;
```python
def f_C1(C1, m):
    # Правая часть уравнения для dC1/dl.
    # C1 — концентрация бензола, моль/м^3.
    # m — массовый расход реакционной среды, кг/с.

    C1 = (-C1 * (k1 + k3) * ro * np.pi * (D ** 2)) / (4 * m)
    return C1
```
- `f_C2(C1, C2, m)` — правая часть уравнения для изменения концентрации компонента `C2`.
```python
def f_C2(C1, C2, m):
    # Правая часть уравнения для dC2/dl.
    # C1 — концентрация бензола, моль/м^3.
    # C2 — концентрация малеинового ангидрида, моль/м^3.
    # m — массовый расход реакционной среды, кг/с.

    C2 = ((k1 * C1 - k2 * C2) * ro * np.pi * (D ** 2)) / (4 * m)
    return C2
```

Эти функции используются при численном интегрировании модели по длине реактора.

#### 5.1.3 Основная подпрограмма расчета

Ключевой функцией является:

- `calculating_model(L)` — выполняет расчет математической модели при заданной длине `L`.

Внутри `calculating_model(L)` выполняются следующие шаги:
1. Расчет входной концентрации исходного компонента на основе массовых расходов и молярной массы.
```python
C1 = (m_c1 * ro) / ((m_c1 + m_O2) * mu_C1)
```
2. Инициализация начальных условий (`C1`, `C2`) и массивов для хранения результатов.
3. Численное интегрирование по длине реактора методом Эйлера:
   - на каждом шаге пересчитываются `C1` и `C2` по правым частям `f_C1` и `f_C2`;
   - сохраняются значения концентраций и координаты по длине.
```python
while l < L:
    C1_0 = C1
    C1 += f_C1(C1, m0) * d_l
    C2 += f_C2(C1_0, C2, m0) * d_l
    l += d_l
```
4. Возврат рассчитанных массивов и итогового значения выходной концентрации продукта.

Функция возвращает:
- итоговую концентрацию целевого продукта;
- массивы концентраций реагента и продукта;
- массив координат по длине реактора.

Результат расчета используется:
- для проверки корректности стационарной модели (вывод концентраций и построение графиков);
- как целевая функция при оптимизации параметра `L` в модуле `golden_ratio.py`.
