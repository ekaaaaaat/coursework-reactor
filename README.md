# Программный комплекс для моделирования и оптимизации химического реактора окисления бензола C6H6 до малеинового ангидрида C4H2O3

## 1. Общие сведения

### 1.1 Назначение программы

Данный программный комплекс разработан в рамках выполнения курсовой работы и предназначен
для математического моделирования, оптимизации и имитационного исследования химического
реактора с учетом кинетики химических реакций и случайных входных воздействий.

Программа позволяет:
- рассчитывать стационарную математическую модель реактора;
- выполнять оптимизацию параметров объекта проектирования;
- моделировать случайные процессы с заданными статистическими характеристиками;
- исследовать динамику реактора при случайных входных воздействиях.

---

### 1.2 Обозначение и наименование программы

Наименование программы:  
**«Программный комплекс моделирования и оптимизации химического реактора»**

Обозначение программы используется условно и соответствует тематике курсовой работы.

---

### 1.3 Язык программирования и среда разработки

Программа реализована на языке программирования **Python** версии 3.9 и выше.

В процессе разработки использовались следующие библиотеки:
- `numpy` — для численных расчетов и работы с массивами данных;
- `matplotlib` — для визуализации результатов расчетов;
- `tabulate` — для формирования табличного представления результатов.

Разработка и отладка программы выполнялась в интегрированной среде разработки **PyCharm**.

## 2. Функциональное назначение программы

Программный комплекс предназначен для исследования и анализа процессов,
протекающих в химическом реакторе, на основе математического моделирования,
методов оптимизации и имитационного моделирования.

Основными функциональными возможностями программы являются:

- расчет стационарной математической модели химического реактора
  на основе системы дифференциальных уравнений, описывающих кинетику
  химических реакций;

- оптимизация варьируемых параметров объекта проектирования
  с использованием метода золотого сечения;

- генерация случайных процессов с заданными статистическими характеристиками
  (математическое ожидание, дисперсия, корреляционная функция);

- имитационное моделирование входных воздействий на объект управления
  с целью исследования устойчивости и динамики системы;

- расчет динамической модели реактора при случайных входных воздействиях
  и анализ изменения выходных концентраций во времени;

- визуализация результатов расчетов в виде графиков и таблиц,
  обеспечивающих наглядное представление полученных данных.

## 3. Состав и структура программного комплекса

Программный комплекс имеет модульную структуру и состоит из набора
взаимосвязанных файлов, каждый из которых реализует отдельный этап
моделирования, оптимизации или имитационного эксперимента.

### 3.1 Состав программных модулей

В состав программного комплекса входят следующие основные модули:

- **`mat_model.py`** — модуль расчета стационарной математической модели
  химического реактора. Содержит реализацию системы уравнений,
  описывающих кинетику реакций, и функцию для вычисления выходных
  концентраций при заданных параметрах;

- **`golden_ratio.py`** — модуль оптимизации, реализующий метод золотого
  сечения. Используется для поиска оптимального значения варьируемого
  параметра объекта проектирования на основе целевой функции;

- **`simulation_modeling.py`** — модуль имитационного моделирования,
  предназначенный для генерации случайного процесса с заданными
  статистическими характеристиками. Формирует входное воздействие
  для динамической модели;

- **`mat_model_dinam.py`** — модуль динамического моделирования,
  реализующий расчет изменения концентраций компонентов во времени
  при наличии случайного входного воздействия;

- **`README.md`** — файл документации, содержащий описание структуры,
  назначения и порядка использования программного комплекса.

---

### 3.2 Взаимосвязь модулей

Работа программного комплекса организована по этапному принципу.

На первом этапе выполняется расчет стационарной математической модели
реактора с использованием модуля `mat_model.py`.

На втором этапе производится оптимизация параметров объекта
проектирования с применением метода золотого сечения,
реализованного в модуле `golden_ratio.py`.

На третьем этапе формируется случайный процесс с заданными
характеристиками при помощи модуля `simulation_modeling.py`.

На заключительном этапе выполняется расчет динамической модели
реактора с учетом случайного входного воздействия с использованием
модуля `mat_model_dinam.py`.
