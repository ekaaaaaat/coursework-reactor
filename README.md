## 5. Описание основных алгоритмов и подпрограмм

В данном разделе приводится описание ключевых модулей программы,
их назначение и логическая структура реализованных алгоритмов.

### 5.1 Модуль `mat_model.py` — математическая модель статики реактора

Модуль `mat_model.py` предназначен для расчета стационарного распределения
концентраций компонентов в реакторе в зависимости от длины реакционной зоны `L`.
Расчет основан на кинетической схеме химических реакций и уравнениях материального баланса.

#### 5.1.1 Исходные параметры и константы

В модуле задаются:
- физические и технологические параметры (температура `T`, диаметр реактора `D`,
  массовые расходы компонентов, плотность среды `ro`);
- параметры кинетики реакций (`A1…A3`, `E1…E3`);
- молярные массы компонентов (`mu_C1`, `mu_C2`);
- варьируемый параметр `L` и шаг интегрирования `d_l`.

Константы скоростей реакций вычисляются по уравнению Аррениуса, что обеспечивает
зависимость кинетики от температуры.


#### 5.1.2 Вспомогательные подпрограммы

В модуле реализованы вспомогательные функции:

- `percent_C(C_m, mu)` — перевод концентрации в массовую долю (в процентах); 
```python
def percent_C(C_m, mu):
    C = (C_m * 100 * mu) / ro
    return C
```
- `f_C1(C1, m)` — правая часть уравнения для изменения концентрации компонента `C1`;
```python
def f_C1(C1, m):
    # Правая часть уравнения для dC1/dl.
    # C1 — концентрация бензола, моль/м^3.
    # m — массовый расход реакционной среды, кг/с.

    C1 = (-C1 * (k1 + k3) * ro * np.pi * (D ** 2)) / (4 * m)
    return C1
```
- `f_C2(C1, C2, m)` — правая часть уравнения для изменения концентрации компонента `C2`.
```python
def f_C2(C1, C2, m):
    # Правая часть уравнения для dC2/dl.
    # C1 — концентрация бензола, моль/м^3.
    # C2 — концентрация малеинового ангидрида, моль/м^3.
    # m — массовый расход реакционной среды, кг/с.

    C2 = ((k1 * C1 - k2 * C2) * ro * np.pi * (D ** 2)) / (4 * m)
    return C2
```

Эти функции используются при численном интегрировании модели по длине реактора.

#### 5.1.3 Основная подпрограмма расчета

Ключевой функцией является:

- `calculating_model(L)` — выполняет расчет математической модели при заданной длине `L`.

Внутри `calculating_model(L)` выполняются следующие шаги:
1. Расчет входной концентрации исходного компонента на основе массовых расходов и молярной массы.
```python
C1 = (m_c1 * ro) / ((m_c1 + m_O2) * mu_C1)
```
2. Инициализация начальных условий (`C1`, `C2`) и массивов для хранения результатов.
3. Численное интегрирование по длине реактора методом Эйлера:
   - на каждом шаге пересчитываются `C1` и `C2` по правым частям `f_C1` и `f_C2`;
   - сохраняются значения концентраций и координаты по длине.
```python
while l < L:
    C1_0 = C1
    C1 += f_C1(C1, m0) * d_l
    C2 += f_C2(C1_0, C2, m0) * d_l
    l += d_l
```
4. Возврат рассчитанных массивов и итогового значения выходной концентрации продукта.

Функция возвращает:
- итоговую концентрацию целевого продукта;
- массивы концентраций реагента и продукта;
- массив координат по длине реактора.

Результат расчета используется:
- для проверки корректности стационарной модели (вывод концентраций и построение графиков);
- как целевая функция при оптимизации параметра `L` в модуле `golden_ratio.py`.

### 5.2 Модуль `golden_ratio.py` — оптимизация параметров методом золотого сечения

Модуль `golden_ratio.py` предназначен для оптимизации варьируемых параметров
объекта проектирования на основе ранее разработанной математической модели.
В качестве метода оптимизации используется метод золотого сечения, обеспечивающий
поиск экстремума целевой функции без использования производных.

---

#### 5.2.1 Назначение и область применения

Метод золотого сечения применяется для поиска оптимального значения параметра
в заданном интервале при условии, что целевая функция является унимодальной.
В рамках данного программного комплекса метод используется для:

- проверки корректности реализации алгоритма оптимизации на тестовой функции;
- поиска оптимального значения длины реактора `L`,
  обеспечивающего максимальное значение выходной концентрации целевого продукта.

---

#### 5.2.2 Целевая функция и тип экстремума

В модуле реализована возможность оптимизации как функции минимума,
так и функции максимума. Для этого используется логика определения
типа экстремума на заданном интервале.

```python
def type_of_extremum(a_, b_, f_):
    # Функция для определения типа экстремума
    c = (a_ + b_) / 2
    if f_(a_) > f_(c) or f_(b_) > f_(c):
        type_ex = 'минимум'
    else:
        type_ex = 'максимум'
    return type_ex
```

В зависимости от типа экстремума выбирается либо исходная целевая функция,
либо функция с противоположным знаком.

---

#### 5.2.3 Алгоритм метода золотого сечения

Алгоритм метода золотого сечения реализован в виде итерационной процедуры,
последовательно сужающей интервал поиска экстремума.

Основные этапы алгоритма:
1. Задание начального интервала поиска.
2. Вычисление внутренних точек интервала на основе коэффициента золотого сечения.
3. Сравнение значений целевой функции в вычисленных точках.
4. Сужение интервала в зависимости от результата сравнения.
5. Повторение процедуры до достижения заданной точности.

```python
def golden_ratio(a_, b_, f_, eps_):
    # Метод золотого сечения для поиска минимума функции f_ на интервале [a_, b_]

    ak, bk, x_list = [], [], []

    left = a_
    right = b_
    t = (3 - np.sqrt(5)) / 2

    ak.append(left)
    bk.append(right)
    x = (left + right) / 2
    x_list.append(x)

    x1 = left + (right - left) * t
    x2 = right - (right - left) * t
    f1 = f_(x1)
    f2 = f_(x2)

    while abs(left - right) > eps_:
        if f1 < f2:
            right = x2
            x2 = x1
            f2 = f1
            x1 = left + (right - left) * t
            f1 = f_(x1)
        else:
            left = x1
            x1 = x2
            f1 = f2
            x2 = right - (right - left) * t
            f2 = f_(x2)

        ak.append(left)
        bk.append(right)
        x = (left + right) / 2
        x_list.append(x)

    return ak, bk, x_list
```

---

#### 5.2.4 Интеграция с математической моделью

Для оптимизации параметров реального объекта проектирования
метод золотого сечения интегрирован с математической моделью реактора.

Для этого используются специальные обёрточные функции, обеспечивающие
корректную передачу варьируемого параметра в модель и возврат значения
целевой функции.

```python
def positive_calculating_model(L):
    # Функция для получения только выходной концентрации С2 из подпрограммы ММ (для использования при оптимизации)
    C2, _, _, _, _, _ = calculating_model(L)
    return C2


def negative_calculating_model(L):
    # Функция для получения только выходной концентрации С2 из подпрограммы ММ
    # с противоположным знаком (экстремум максимум)
    C2, _, _, _, _, _ = calculating_model(L)
    return -C2
```

Такая структура позволяет применять единый алгоритм оптимизации
как к тестовым функциям, так и к сложным математическим моделям.

#### 5.3.1 Исходные параметры имитационного эксперимента

---

#### 5.3.2 Генерация базовой последовательности случайных чисел

Для формирования исходной последовательности используется конгруэнтный метод.
Результатом данного этапа является нормированная последовательность `x(k)`.

```python
def generation_congurent_method(n, lam1, lam2, x0):
    # Функция генерации случайных чисел (Конгруэнтный метод)
    x = [x0]
    for i in range(1, n):
        x.append((lam1 * x[i-1]) % lam2)
    x_norm = [xi / lam2 - 0.5 for xi in x]  # нормализация в [-0.5; 0.5]
    return x_norm
```

---

#### 5.3.3 Расчет статистических характеристик

После получения последовательности `x(k)` вычисляются:
- математическое ожидание;
- дисперсия;

При необходимости выполняется центрирование последовательности,
если математическое ожидание отличается от нуля выше заданного порога.


> функции `checkmate_waiting(...)`, `dispersion(...)`
> и ветвление центрирования последовательности

---

#### 5.3.4 Аппроксимация корреляционной функции

Для оценки параметра корреляции случайного процесса используется аппроксимация
корреляционной функции экспоненциальной моделью вида  
`K(S) ≈ σ² · exp(-α · S)`.

На данном этапе определяется оценка `alpha_z`, а также формируется массив аппроксимированных
значений корреляции для последующей визуализации.

---

#### 5.3.5 Формирование случайного процесса z(k)

На основе последовательности `x(k)` формируется случайный процесс `z(k)` с заданными
характеристиками.

```python
def generate_process_z(x, A1, A2, sigma0_2, sigma_x0_2, alpha0, M0, Ns):
    # Функция генерации случайного процесса
    z = []
    for k in range(len(x) - Ns):
        ssum = 0
        for i in range(k, k + Ns):
            ssum += x[i] * math.sqrt(sigma0_2 / (sigma_x0_2 * alpha0 * A2)) * A1 * math.exp(-A2 * alpha0 * abs(i - k))
        z.append((1 / Ns) * ssum + M0)
    return z
```

---

#### 5.3.6 Контроль точности и уточнение параметров

После генерации процесса вычисляются его характеристики (`Mz`, `sigma_z2`, `alpha_z`) и выполняется
проверка отклонения от заданных значений  `is_within_tolerance(...)`. Если отклонение превышает допустимый порог (10%),
выполняется автоматическая корректировка параметров модели формирования процесса.

Уточнение параметров реализовано методом градиентного поиска `gradient_search(...)`: производится оценка ошибки и
итерационное изменение коэффициентов модели до достижения допустимого уровня.

Результаты визуализируются на графиках:

### 5.4 Модуль `mat_model_dinam.py` — модель динамики реактора при случайном входном воздействии

Модуль `mat_model_dinam.py` предназначен для исследования динамического поведения реактора
при наличии случайного входного воздействия. В качестве входного сигнала используется
случайный процесс, сформированный модулем `simulation_modeling.py`. Результатом работы
является зависимость выходной концентрации целевого продукта от времени, а также
оценка реакции системы на случайные изменения входных параметров.

---

#### 5.4.1 Назначение и место модуля в программном комплексе

Динамическая модель используется на завершающем этапе выполнения курсовой работы —
при проведении имитационного эксперимента. Модуль решает задачу расчета выходных
параметров реактора в условиях, близких к реальной эксплуатации, когда входные
воздействия являются случайными и изменяются во времени.

Основные задачи модуля:
- учет изменения входной концентрации во времени;
- расчет отклика реактора на входной случайный сигнал;
- получение временной зависимости выходной концентрации продукта;
- построение графиков входного и выходного сигналов для анализа динамики.

---

#### 5.4.2 Логическая структура вычислений

Логическая структура модуля включает следующие основные этапы:

1. Инициализация физических и кинетических параметров реактора
   и вычисление величин, необходимых для перехода к динамическому расчету
   (в том числе параметров, связанных с временем пребывания).

2. Определение функций правых частей, описывающих изменение концентраций
   реагента и продукта в реакционной зоне.

3. Формирование входного воздействия как функции времени на основе
   сгенерированного случайного процесса.

4. Численное интегрирование модели по расчетной области с накоплением
   значений концентраций в узлах расчетной сетки.

5. Формирование выходных массивов:
   - временной сетки;
   - значений выходной концентрации;
   - вспомогательных данных для анализа и визуализации.

6. Построение графиков:
   - входного воздействия во времени;
   - выходной концентрации целевого продукта во времени;
   - дополнительных графиков (при необходимости) для анализа распределений.

---

#### 5.4.3 Расчетная область и метод характеристик

Расчет выполняется в характеристических координатах α и β.
Область определения разбивается на несколько участков в зависимости
от взаимного положения характеристик и границ расчетного интервала времени.

Для корректного учета входного воздействия и времени пребывания
реализован расчет в двух расчетных областях:

- **Область II**, в которой характеристика полностью проходит
  через реакционную зону;
- **Область III**, в которой характеристика частично пересекает
  расчетную область.

Для каждой области задаются собственные границы интегрирования
и начальные условия, определяемые входным сигналом и параметрами реактора.

---

#### 5.4.4 Численное интегрирование вдоль характеристик

Вдоль каждой характеристики выполняется численное интегрирование
системы обыкновенных дифференциальных уравнений, описывающих
изменение концентраций реагента и продукта.

Интегрирование осуществляется пошагово с использованием
фиксированного шага по характеристической переменной.
На каждом шаге вычисляются:
- текущие значения концентраций;
- соответствующие значения времени и координаты реактора.

Результаты интегрирования накапливаются в массивах,
которые используются для последующего анализа и визуализации.

---

#### 5.4.5 Формирование выходных данных и визуализация

По результатам расчета динамической модели формируются:
- временная зависимость входной концентрации реагента;
- временная зависимость выходной концентрации целевого продукта;
- массивы данных для анализа распределений концентраций.

Для наглядного представления результатов выполняется построение графиков:
- входного случайного воздействия во времени;
- выходной концентрации продукта во времени;
- отметки среднего времени пребывания в реакторе.

Полученные результаты используются для окончательной проверки
работоспособности объекта проектирования методом имитационного моделирования
и подтверждения корректности выбранных параметров системы.
